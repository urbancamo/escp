Implementation Stages:

1. Create the codebase structure suitable for a C-based program that will.
   compile on Macos, Linux and other posix-compliant Unix systems.
2. Review the documentation in the reference section.
3. Create a Markdown table of ESC/P commands that will be supported and are appropriate.
4. Map the ESC/P commands to command line arguments.
5. Choose suitable support libraries for the program.
6. Create the program including Makefile
7. Create tests for the program that can be run from the makefile and check all command
   line options.
8. Create documentation for the program in the form of a markdown file and man page.
