# ESC/P Printer Utility

This program allow the user to configure an Epson-compatible Dot Matrix Printer.
It follows the unix convention of a 'small utility that does one thing' and is designed
to sit in a pipeline of commands that convert a text file into a file suitable for printing
on an ESC/P compatible printer.
